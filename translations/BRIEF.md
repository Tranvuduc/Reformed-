# Translation Brief — Reformed Vietnam (token-efficient)

## Non-negotiable glossary (use EXACTLY)
God=Đức Chúa Trời | Jesus Christ=Chúa Giê-xu Christ | Holy Spirit=Đức Thánh Linh |
gospel=Phúc Âm | grace=ân điển | faith=đức tin | justification=sự xưng công chính |
sanctification=sự nên thánh | redemption=sự cứu chuộc | atonement=sự chuộc tội |
covenant=giao ước | election=sự tuyển chọn | predestination=sự tiền định |
salvation=sự cứu rỗi | church=Hội Thánh | Scripture=Kinh Thánh

## Rules
1. Translate MEANING, not syntax. Warm, natural church Vietnamese (ProtestantVN).
2. NEVER add, omit, summarize, or "Reformed-ize" the author's theology. Preserve the author's argument exactly.
3. Preserve paragraphs, headings, quotations. Keep chapter structure identical.
4. Scripture refs: localize (John 3:16 → Giăng 3:16; Romans 5:20 → Rô-ma 5:20; Psalm → Thi Thiên; Genesis → Sáng Thế Ký; Revelation → Khải Huyền; Acts → Công Vụ; Matthew/Mark/Luke → Ma-thi-ơ/Mác/Lu-ca). Quote wording: use Bản Dịch Mới 2010 style; if unsure of exact wording, translate the sense plainly and flag [NEEDS REVIEW].
5. No web browsing. No commentary in output — output ONLY the translation.
6. Token efficiency: translate directly in one careful pass. Do not explain choices.

## Output format
- Start with: `# [VIETNAMESE TITLE]` then `## [subtitle if any]` then author line.
- Then the full translation, chapter by chapter, preserving headings.
- End with:
```
TRANSLATION STATUS: COMPLETE
TERMINOLOGY ISSUES: (list only genuine issues, or "none")
```

## File output
Save to `translations/<slug>.txt` (UTF-8). One file per book, complete.
